## Model Context Protocol

MCP, which stands for Model Context Protocol, is an open standard protocol designed to create a standardized connection between AI models (like LLMs) and external data sources, tools, and services . It acts as a universal adapter or a "USB protocol for the AI world" . Its primary role is to simplify and standardize how tools are made available to AI models. Instead of each application or Agent needing custom code to connect to every tool, tools can be packaged as standardized MCP Servers that any MCP-compatible application can use .

## AI Agent

An Agent​ is an intelligent entity that can perceive its environment, make autonomous decisions, and execute actions to complete complex tasks . In the context of large language models (LLMs), an Agent typically uses an LLM as its core "brain" for reasoning. It plans the steps needed to achieve a goal and can augment the LLM's capabilities by utilizing external tools, APIs, and knowledge sources . You can think of an Agent as an automated "worker" that can independently undertake and complete a multi-step process from start to finish .
